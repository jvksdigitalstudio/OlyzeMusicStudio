# Documentación de nivel de proyecto

Aquí vive la documentación del proyecto completo (`:app` + `:eliner` +
cualquier módulo futuro) y, en [`eliner/`](eliner/), la del motor:
[`ARCHITECTURE.md`](eliner/ARCHITECTURE.md) (estructura vigente y capas),
[`ROADMAP_MODULES.md`](eliner/ROADMAP_MODULES.md) (módulos previstos, no
implementados) y [`PROJECT_FORMAT_OMS.md`](eliner/PROJECT_FORMAT_OMS.md).
La documentación ya no vive dentro del source set de `:eliner` (ADR 0027).

## Registro de decisiones arquitectónicas (ADR)

Ver [`adr/`](adr/) — un historial breve de por qué se tomó cada decisión
estructural importante, en orden cronológico. Útil para no repetir
discusiones ya resueltas, y para que alguien nuevo en el proyecto entienda
el "por qué" sin tener que leer todo el historial de commits.
