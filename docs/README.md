# Documentación de nivel de proyecto

Esta carpeta es distinta de `eliner/src/main/java/.../eliner/documentation/`
(que documenta la arquitectura *interna* de EliNer). Aquí vive
documentación que aplica al **proyecto completo** (`:app` + `:eliner` +
cualquier módulo futuro), no a un módulo en particular.

## Registro de decisiones arquitectónicas (ADR)

Ver [`adr/`](adr/) — un historial breve de por qué se tomó cada decisión
estructural importante, en orden cronológico. Útil para no repetir
discusiones ya resueltas, y para que alguien nuevo en el proyecto entienda
el "por qué" sin tener que leer todo el historial de commits.
